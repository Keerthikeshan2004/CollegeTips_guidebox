1. Project Overview
The Digital Literacy Campaign (DLC) aims to help people across India become digitally empowered. Our team developed an interactive chatbot that guides users in using digital tools like WhatsApp, Paytm, Google Maps, and more. The chatbot provides clear answers to frequently asked questions and step-by-step tutorials in a fun and beginner-friendly interface.
2. Objectives
Create an easy-to-use chatbot interface for users. Provide educational support on digital tools via FAQs. Offer step-by-step instructions for tasks like sending messages, using UPI, navigating maps, etc. (Bonus) Integrate AI using Dialogflow or ChatGPT API. Deploy the chatbot on the DLC website.
3. Features Implemented
- Chat Interface: - Responsive chat widget - Chat bubbles for user/bot - Input field for user messages - Scrollable conversation panel - Conversation Flow: - Predefined FAQ-based responses - Friendly tone with emojis - Step-by-step instructions for common digital tasks - FAQ Data Handling: - Stored in JSON format - Parsed by JavaScript to respond to user queries
- Covers 15+ essential digital literacy topics - Deployment: - Embedded into the DLC website via <iframe> tag - Hosted on [GitHub Pages / Netlify / Vercel] for public access
